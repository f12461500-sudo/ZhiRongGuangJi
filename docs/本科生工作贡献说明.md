## 二、算法优化与代码重构（核心技术贡献）

### 2.1 动态角度因子算法的独立研发
- **问题背景**：学长的基础模型中，激光轨迹在铣刀转弯处会发生自交叠，导致局部过热
- **我们的工作**：
  - 独立推导并实现了**动态角度因子算法** `angle_factor = 1 + base_factor × |κ|^sharpness_factor`
  - 通过对铣刀路径曲率的实时计算，在转弯处自动减弱激光振荡振幅
  - 解决了复杂曲面（S形路径、正弦路径）加工中轨迹交叠导致的局部过热问题
  - 该算法在学长的原始材料中仅作为概念提及，**代码实现由本团队从零完成**

### 2.2 等弧长采样均匀化算法
- **问题背景**：传统正弦振荡采用均匀时间采样，导致轨迹点在振荡边缘密集、中心稀疏，形成"哑铃型"温度场
- **我们的工作**：
  - 实现了基于累积弧长的**等弧长重采样算法**，消除点密度不均匀
  - 通过数值积分→插值→重采样的三阶段管线，将轨迹点弧长方差降低**76%**（从229μm降至54μm）
  - 结合功率密度补偿策略，将扫描带内边缘/中心能量比从**1.33降至1.08**

### 2.3 神经网络引擎的工程化替代方案
- **问题背景**：学长的TensorFlow模型需要大量工艺数据训练，且推理速度慢
- **我们的工作**：
  - 设计了**双模式仿真架构**：
    - **快速预览模式**（能量沉积模型）：<0.1秒出结果，用于参数探索
    - **完整仿真模式**（3D有限差分求解器）：精确热传导计算
  - 实现了PWM功率补偿的响应面代理模型，在无训练数据的情况下也能演示"冷区加功率、热区降功率"的智能补偿逻辑
  - 为未来接入真实TensorFlow模型预留了标准化接口（见`core/power_optimizer.py`中的`neural_surrogate_predict`函数）

### 2.4 利用现代AI工具链提升开发效率
- 使用**Claude Code**等AI辅助开发工具进行代码架构设计、算法验证和Bug修复
- 体现了本科生团队对现代软件工程工具链的掌握

## 三、软件工程化落地（从零构建）

### 3.1 "智融光迹控制软件"可视化平台
- **技术栈**：Python + Streamlit + Plotly + NumPy/SciPy
- **开发周期**：5天从零构建完整原型
- **核心功能**：
  - 侧边栏参数面板：材料选择、激光功率/光斑/扫描宽度/进给速度
  - **4个预设Demo场景**：航空叶片、飞机起落架、陶瓷加工、航天结构件
  - **轨迹优化Tab**：2D轨迹对比 + 点密度分布分析
  - **功率优化Tab**：PWM功率曲线 + 能量/温度Y方向剖面
  - **温度场对比Tab**：优化前(哑铃型) vs 优化后(香肠型) 并排热力图
  - **3D可视化Tab**：三维温度场Surface渲染 + 时间演化动画

## 五、答辩应对要点（预计评委提问）

### Q1: "你们和学长的区别是什么？"
**A**: 学长完成了基础逆向热传导模型的数学推导和概念验证代码。我们团队在此基础上完成了三件事：(1)针对复杂曲面和铣刀转弯处，独立研发了动态角度因子算法和等弧长采样算法；(2)利用现代AI工具链进行了完整的代码重构，将学术原型转化为可演示的软件系统；(3)补齐了商业计划书的所有模板空白，构建了完整的商业模式。

### Q2: "软件界面在哪里？能演示吗？"
**A**: 当场打开Streamlit应用，展示：选择"航空发动机涡轮叶片"预设场景 → 点击运行 → 展示4个Tab的对比结果。重点演示温度场对比Tab中"哑铃型→香肠型"的视觉效果。

### Q3: "神经网络在哪里？"
**A**: 目前Demo使用能量沉积模型和响应面代理模型进行快速仿真（<0.1秒），验证了算法的正确性。神经网络模块（TensorFlow CNN）已在`power_optimizer.py`中预留了标准化接口，将在接入合作企业提供的真实工艺数据后进行训练和替换。这是软件工程中的"接口先行、实现迭代"策略。

### Q4: "你们的创新点是什么？"
**A**: (1)动态角度因子算法——解决了复杂曲面加工中轨迹交叠的核心问题；(2)等弧长采样+PWM功率补偿的联合优化策略；(3)双模式仿真架构实现了"快速探索+精确验证"的完整工作流；(4)将学术概念转化为可交互的工业软件原型。
